# 纸面技术插画语法

v0.3补充：图片方法不局限于SVG，先读 `image-workflow.md`。本参考规定解释图的几何/状态/图形语法；同样适用于生成技术插图的结构核查，不把AI情境图当结构证据。

## 保留 Anatomy 的工艺，不保留交互网页的限制
用实体体积、合理接触/遮挡、工艺细节和统一模型让机器读起来像一件真实物品。不要全图裸线框和漂浮盒子；不要满屏标签挤成海报。但纸面必须允许编号、箭头、剖面和必要说明。

## 各种图的任务
- 总览：定位器物与主要关系，常用等轴测/轴测，细节适度。
- 剖面：露出外壳遮住的关键内部路径，剖切边界和截面材料要明确。不是透明化所有表面。
- 爆炸：说明装配层次，位移方向一致，保持轴/接口对应；不强求所有零件被拆开。
- 流路：强调力/水/电/信息的连续路径，允许正投影视图和语义箭头。
- 状态序列：同一个模型/视角/编号表示前后变化，改变条件写在每一格上。
- 局部放大：标出取景区域和对应件号，不创造另一个结构。
- 对比：共享比例、图例和基线，结论从可比较差异得出。

## 全书视觉约定
纸白/温白背景，深灰主线；结构退一层，关键路径加粗/单强调色。运动、物料、信号使用不同箭头或线型，并在首用处讲清楚；箭头端点落到真实部件/接口，不插进无关零件。线型+编号同时承载语义，不能只靠红绿区分。

每个真实部件都有稳定ID和中文术语，必要时附英文。各图 ID 相同意味着同一个部件，不因局部放大而重新编号。部件颜色可用，但不是每个件一个颜色。标签横排不随轴测面倾斜；引出线走短且少交叉的路径，不遮住关键接触/运动。

## 纸面尺寸
在最终页面实际图宽下检查，而不是SVG浏览器放大后看。标签建议最终不少于9pt，正文约10.5–11pt，图注约9pt；复杂图宁可拆分。重要细线可印可看，不用屏幕上的极淡灰。PNG兼容层按最终宽度准备约300DPI的像素量；例如160mm宽需要约1890px，计算由工具执行，不手算到处复制。

## 科学正确性
- 真实结构：查壳体、动力源、接口、阀/转轴和力/物流路径，不能“像机器”就算通过。
- 概念类比：先列概念操作到图上动作的一一对应，明确不对应现实机械的部分。
- 运动：方向、前后顺序、限位与能量来源应一致。齿轮和链条不能凭图画位置创造不存在的传动。
- 程序状态：用模型自动导出状态列表，然后排成图，不画错淘汰对象再写一个解释圆回来。

## SVG 安全与兼容
SVG静态自包含，必须有viewBox/尺寸，拒绝script/事件属性/foreignObject/远程链接/外部CSS。样式和色值内联，避免网页继承导致空白。CSS可使用自包含style但不要引用URL；svg image资源若确需使用必须内嵌且许可清楚。字体使用目标机器可用字体，保存显示检查结果，不把不存在的字体名当保障。

## Vendor 接口
`assets/vendor/anatomy/kit/iso-kit.mjs` 提供轴测投影、实体和SVG构建；`references/kit.md`与`craft.md`是API/工艺参考。先阅读会实际调用的接口，不猜函数名。原来的交互卡片、Fig编号UI、黑暗背景和禁止标注不是本书必需；可以只用其几何原语组成纸面图。

`figure-smoke.mjs`验证kit可执行和静态SVG生成，不是正式样书图。主题图的几何、标签和路径存项目脚本，不修改vendored源。
